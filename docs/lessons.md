# Lessons

**Lessons** is the published memory catalog, scored against whether each lesson is still
catching anything. Candidates stay in Memory review until you stand behind them; this is what you already have.

## Main actions

- **Filter** by state: Dropping (score falling), Missed (surfaced but did not catch), Unmeasured
  (no outcomes recorded), Overlap (near-duplicates; keep one, retire the rest into it),
  Promote (eligible for org-wide reach) and Unclassified (no lesson class).
- **Open a lesson** for provenance, outcomes and history.
- **Retire overlaps** into the one you keep.
- **Promote** to org reach from the detail page while the lesson is project-reach. It shows the
  real reason when disabled. There is no separate org-catalog page; a promoted lesson shows on
  sibling project lists.

## Reading an empty result

An empty catalog is not a high score. Caught-issues and effectiveness stay **unknown** until
something is counted; quiet time does not raise a score. A missing measurement makes a lesson
unverifiable, not ineligible, and unverifiable cannot be overridden.
